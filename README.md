- 双栏时列表使用紧凑图标，目录操作收进三点菜单。新建、重命名、移入回收站后两侧刷新。
- 沿用原应用 ID 与证书，versionCode 5，覆盖安装保留现有数据。

## 当前功能

- 返回改为左上角小折角，保留 48dp 点击区域；预览标题单行显示，并为状态栏和导航栏留白。
- 文件菜单“移入回收站”：可恢复单项或全部，名称冲突时另起名称；永久删除和清空必须确认。回收站不自动清理。
- 设置 → 回收站与 ZIP 备份：选择并记住外部备份目录，生成 ZIP；默认包含回收站，可取消勾选。
- 备份先在内部生成并校验，再复制到选定目录，回读核对 SHA-256。失败不报告成功。
- 支持导入匣子备份或普通 ZIP，先展示数量和空间，再在临时目录验证 CRC、大小；匣子备份还验证逐文件 SHA-256。
- 恢复完成后生成独立的“导入备份-日期-编号”文件夹，不覆盖或合并现有文件。备份中的回收站保存在这个独立文件夹内，不加入当前回收站。
- 应用 ID 为 com.pocketvault.app，当前版本 0.2.1 / versionCode 5；沿用原私有存储路径。

## 已有功能

单/多文件收纳、接收系统分享、待整理目录、文件夹浏览与新建、重命名、文件名搜索、排序、多选分享、单文件导出副本、外部应用打开。
导入流式复制、同步落盘并核对 SHA-256，始终保留外部原文件。图片采样显示、UTF-8 文本只读前 1MB、PDF 前后翻页。
暖白和蓝白两种主题，共用布局。不申请网络或全盘访问权限，无账号、广告或密码。内部文件不向普通文件管理器或相册枚举；选中文件才授予外部应用临时只读权限。

## 使用和限制

1. 文件仍保存在 Context.filesDir/vault，删除移入相邻私有 vault-trash。卸载应用或清除数据会删除内部文件和回收站，外部 ZIP 应单独保管。
2. ZIP 未加密；本应用依赖 Android 沙箱，也不是加密保险箱。外部应用取得临时读取权限后可能自行复制文件。
3. 备份、恢复时保持页面打开，支持取消；尚无后台通知、断点续传、杀进程任务恢复。进程中止可能留下内部临时文件，本版不自动清理。
4. 恢复需要同时容纳压缩包缓存与展开内容；文件数上限 20,000、展开总量 64GiB、导入 ZIP 大小 8GiB，并预留 16MiB 空间。路径最多 64 层，单段最多 180 字符。不支持隐藏路径（匣子自身恢复标记除外）、符号链接、加密 ZIP；拒绝绝对路径、越界、重复路径和异常压缩比。
5. 超过 512MiB 且压缩比超过 1000 的 ZIP 被拒绝。使用平台 ZIP 实现，尚未真机验证多 GB 或 ZIP64 边界。
6. SAF 目录权限、空间信息、持久授权与回读能力取决于提供方。首次使用需要系统目录选择器授权；权限失效时请重新选择目录。
7. 图片尚无 EXIF 旋转、双指缩放及超长图阅读；文本仅 UTF-8，HTML/SVG 不执行脚本。音视频交由外部播放器。
8. 已移除旧异常报告弹窗和记录功能。
9. 继承 0.1.2 的规范路径修复，保持对路径越界和外部符号链接的检查。

尚未实现：文件夹批量导入、仓库内移动/复制、收藏/分类、归还原位、恢复合并、文本编辑、内置音视频和播放进度。文件身份仍以相对路径定位，尚无完整 UUID 索引。本版不等同完整需求 V1.0。
